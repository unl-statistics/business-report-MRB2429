Data Documentation

Goal

The goal of this report is to estimate the risk of a bridge collapse in Omaha, Nebraska over the next five years.

Risk = Probability of failure × Consequence of failure

Source 1: National Bridge Inventory

The data comes from the Federal Highway Administration’s National Bridge Inventory [@fhwa_nbi]. This dataset provides information about bridge age, condition ratings, location, and traffic levels. The main variables used from this dataset are shown in Table 1.

Important Variables

These variables help show the condition of each bridge. Lower condition ratings indicate a greater chance of structural problems. Bridge age is also an important factor because older bridges are more likely to show wear over time.

There is a possible issue with missing data in the dataset. Some bridges may not have complete ratings for every condition measure. If data is missing, those bridges will either be removed from the analysis or reviewed carefully so the results are not misleading.

Source 2: Nebraska Department of Transportation

These state bridge reports are from NDOT [@ndot_bridge]. This source adds more local information about repairs and maintenance plans, which can help when looking at short term risk. The main variables used from this source are shown in Table 2.

Important Variables

This source is useful because a bridge with planned repairs or available funding may have lower short term risk than a bridge with no repair plans. It also helps add more local context that may not be fully shown in the national bridge inventory data.

Source 3: Traffic Data

This is traffic data that comes from FHWA Highway Statistics. [@fhwa_stats]. This source is mainly used to help estimate the consequences of a bridge collapse instead of the probability of one actually happening.The main variables used from this source are shown in Table 3.

Important Variables

This data helps show how serious the consequences would be if a bridge collapsed. A bridge that carries a high amount of traffic, especially truck traffic, would more likely cause more problems.

Is this enough data?

I do think it is enough data. Each source provides me with different things that could help assess and prevent the bridge collapse risk in Omaha over the next five years. The NBI data provides the probability of a bridge collapsing. The NDOT data helps with local repair information, and the traffic data measure the impact. I think they work together very well.
